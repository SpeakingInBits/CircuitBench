## Install

In VS Code 1.100 or later, open the Extensions view, search for **Circuit Bench**, and select **Install**. You can also get it from the [Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=SpeakingInBits.circuit-bench). VS Code keeps it up to date from there.

To try it, open the Command Palette and run **Circuit Bench: New Project from Example**.

### Install this version from a file

1. Download [circuit-bench-{{VERSION}}.vsix](https://github.com/SpeakingInBits/CircuitBench/releases/download/v{{VERSION}}/circuit-bench-{{VERSION}}.vsix).
2. In the Extensions view, select **...** at the top, and choose **Install from VSIX...**.
3. Pick the file you downloaded.
